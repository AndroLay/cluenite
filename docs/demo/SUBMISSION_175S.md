## English narration

### S1 — 00:00–00:12

What if chat could solve a mystery while you take a break? This is Cluenite: a Twitch-native mystery game for streamers and their communities.

### S2 — 00:12–00:35

Viewers play in ordinary Twitch chat. In Quick Case, someone inspects the camera with the look command. The message reaches EventSub, and the overlay releases a clue: tag R zero seven. The streamer keeps their main scene; chat now has something to investigate.

### S3 — 00:35–00:52

Inspect the maintenance schedule, then connect the records. The same robot was scheduled in that gallery at twenty-one ten. The engine checks the proof before revealing the answer. Every useful observation can move the case forward.

### S4 — 00:52–01:20

Quick Case is the short format. Mystery Live gives the community a longer investigation. Inspect the scene, build an evidence board, reconstruct the timeline, and challenge a theory. Here, the festival trophy disappears around a blackout. The obvious explanation is theft. But what happened before the lights went out?

### S5 — 01:20–01:45

Putting the blackout first does not fit the records. The heat warning, safety order, opened display and departing trolley all come earlier. Correct the order, then challenge the theft theory: the authorized move began before the blackout. A theory is tested against evidence, so a wrong guess becomes the next lead.

### S6 — 01:45–02:17

Co-op gives two communities different workstations in the same investigation. The field station scans the signal. The records station checks the maintenance manual. Share both discoveries and the server unlocks a joint proof. Neither community starts with the whole answer. Each side contributes something the other needs, turning a deduction into a shared breakthrough.

**Original responsive fallback, only when paired with responsive footage:** Cluenite is also designed around the streamer's workflow. The guide explains chat commands. Settings keep presentation preferences together, and setup explains how to add the browser overlay. These are the actual local pages at desktop and phone widths. A short mystery can fit around the main broadcast, while Mystery Live gives a community room for a longer investigation.

### S7 — 02:17–02:40

We built Cluenite with OpenAI Codex, starting from case rules. Codex helped implement the engine, EventSub, persistent sessions and realtime updates. Automated tests and real Twitch-to-OBS runs checked the logic. The server verifies evidence; the overlay presents the result.

### S8 — 02:40–02:55

One clue can change the whole story. Cluenite turns downtime into a mystery and chat into investigators. Built for streamers. Solved together.
