# Codex x TwitchCon Hackathon

Cluenite is a Twitch-native detective game: one streamer hosts an investigation while viewers inspect clues, connect evidence and help support the case’s verdict through chat.

## Judge journey

1. Open [Cluenite](https://cluenite-app.onrender.com) and choose **Practice cases** to learn the evidence flow. Practice uses scripted browser content and chat; it is not a live Twitch round.
2. To inspect the Twitch integration, a broadcaster must connect an authorized Twitch account, start Q01, M01 or C01, and use the case commands in channel chat. The server receives Twitch events and validates case progress. This path requires Twitch authorization and a working provider connection.
3. For co-op, two consenting broadcasters investigate separate stations and combine their evidence. A read-only, scoped OBS overlay can show the round on stream.
4. Read the [setup guide](setup.md), [API overview](api.md) and [architecture](architecture.md) for the local implementation and data boundaries.
