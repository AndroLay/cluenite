## Slice J requests (2 November 2026)

Slice J is the frontend completion pass. It added no backend contract change. Three items remain open. Each one needs a decision or evidence that the frontend cannot provide alone. The invitee accept/decline page is built as a frontend proposal; its route still needs a contract decision (second item).

- **REQ-FE-006: co-op invitee identity (open; contract decision).** `POST /api/coops/invitations` requires a numeric `inviteeTwitchId` (`apps/server/src/auth/routes.ts`, around lines 416-418). The host's signed-in UI knows only the host's own login and profile. No server route maps a login name to a numeric Twitch ID for the frontend. The frontend must not guess or construct identities. Options for the backend owner: a server-side lookup that returns the numeric ID for a known account, or a login-only invitation that the server resolves. C01 "Generate invitation" stays disabled until one option is chosen.
- **Invitee accept and decline surface (frontend proposal built; route and link format need a contract decision; not exercised live).** `apps/web/src/site/CoopInvitePage.vue` is served at `/coop/invite`. It calls `POST /api/coops/invitations/:inviteId/accept` and `POST /api/coops/invitations/:inviteId/decline` with an authenticated invitee session, a new `Idempotency-Key` per click, the `X-CSRF-Token` from `GET /api/me`, and body `{token}`. The proposed link is `/coop/invite?invite=<inviteId>#token=<token>`. The token stays in the URL fragment, so it is not sent in the request line or server access logs. The page reads it once, removes it from the address bar, keeps it in memory, and never renders or logs it. Signed-out invitees go through `/api/auth/twitch/start` and then open the original link again. The host's create flow, which would generate these links, is blocked by REQ-FE-006. **Rejoin remains open:** `POST /api/coops/sessions/:sessionId/rejoin` has no frontend entry point, because no route supplies the `sessionId` (no list route; accept returns it only once).
- **Live two-account co-op evidence (open; external).** Co-op acceptance needs two real Twitch accounts and a live session. This has the same dependency as REQ-FE-003.

Slice J does not change the disposition of REQ-FE-003, REQ-FE-005, or the revoked-state request above.

- **REQ-FE-007: live hidden-object search (open; engine, case, and contract work).** The sample's search runs in the browser (`apps/web/src/sampleCase/`): twelve objects with hit boxes on a 10×6 grid, called with `!look <cell>` (for example `!look C4`), with combo and miss scoring. Until then, live rounds keep `!look <clue-id>`, and the guide and sample copy say so.
