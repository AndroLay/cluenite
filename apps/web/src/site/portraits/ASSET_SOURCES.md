# Cast portrait atlas

`cast-atlas-v1.png` is original generated game artwork, created on 2 November 2026 with the built-in imagegen tool. It contains six equally sized 512 x 512 painted portrait cells in a 1536 x 1024 image. `SuspectPortrait.vue` selects cells using CSS background positioning; the source image is preserved without cropping or resampling.

Order: magician (`hat`), captain/conductor (`cap`), auburn-haired woman (`bun`), lighthouse keeper (`beard`), partner detective (`scarf`), harbour clerk (`bob`). These are fictional characters, not photographs or real participant identities. They share warm amber light, period fabrics, human proportions, and an espresso/walnut/burgundy palette. The delivered atlas has warm painted backgrounds; no transparent cutout is claimed.
